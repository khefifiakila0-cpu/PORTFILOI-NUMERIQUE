🏆 Algorithme 1 : Recherche du Maximum dans un Tableau

Idée générale : On suppose que le premier élément est le plus grand, puis on parcourt le reste du tableau en mettant à jour max dès qu'on trouve une valeur supérieure. 

Algorithme RechercheMax
Variables : T : Tableau[1..N] d'Entiers, max, i : Entiers
Début
    max ← T[1]
    Pour i de 2 à N Faire
        Si T[i] > max Alors
            max ← T[i]
        FinSi
    FinPour
    Afficher("Maximum = ", max)
Fin

Complexité : Temporelle en $O(n)$ (un seul parcours du tableau) et spatiale en $O(1)$.

Exemple pas à pas sur [12, 45, 8, 67, 23] : Initialisation max = 12 → 45 > 12 (max = 45) → 8 < 45 (inchangé) → 67 > 45 (max = 67) → 23 < 67 (inchangé). Résultat : 67. 

def recherche_max(T):
    maximum = T[0]
    for val in T[1:]:
        if val > maximum:
            maximum = val
    return maximum

# Exemple d'exécution
print("Maximum :", recherche_max([12, 45, 8, 67, 23]))

🫧 Algorithme 2 : Tri à Bulles + Visualiseur Interactif

Idée générale : Comparer répétitivement les éléments adjacents et les permuter s'ils sont dans le mauvais ordre, faisant « remonter » les plus grandes valeurs à la fin. 

Algorithme TriBulles
Variables : T : Tableau[1..N] d'Entiers, i, j, temp : Entiers
Début
    Pour i de 1 à N - 1 Faire
        Pour j de 1 à N - i Faire
            Si T[j] > T[j + 1] Alors
                temp ← T[j]
                T[j] ← T[j + 1]
                T[j + 1] ← temp
            FinSi
        FinPour
    FinPour
Fin

Complexité : Temporelle en $O(n^2)$ dans le pire cas et cas moyen ($O(n)$ si déjà trié avec booléen d'échange), et spatiale en $O(1)$.

Exemple pas à pas sur [4, 2, 3, 1] (1er passage) : (4,2) → échange → [2, 4, 3, 1] ; (4,3) → échange → [2, 3, 4, 1] ; (4,1) → échange → [2, 3, 1, 4] (4 est placé à la fin). 

def tri_bulles(T):
    n = len(T)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if T[j] > T[j + 1]:
                T[j], T[j + 1] = T[j + 1], T[j]
    return T

# Exemple d'exécution
print("Trié :", tri_bulles([4, 2, 3, 1]))

🔍 Algorithme 3 : Recherche Dichotomique (Tableau Trié)

Idée générale : Diviser par deux l'intervalle de recherche à chaque étape en comparant la valeur cherchée x avec l'élément central T[milieu]. 

Algorithme RechercheDichotomique
Variables : T : Tableau[1..N] trié, x, debut, fin, milieu : Entiers, trouve : Booléen
Début
    debut ← 1 ; fin ← N ; trouve ← Faux
    TantQue (debut <= fin) Et (Non trouve) Faire
        milieu ← (debut + fin) DIV 2
        Si T[milieu] = x Alors
            trouve ← Vrai
        SinonSi T[milieu] < x Alors
            debut ← milieu + 1
        Sinon
            fin ← milieu - 1
        FinSi
    FinTantQue
Fin

Complexité : Temporelle en $O(\log n)$ (division de l'intervalle par 2 à chaque itération) et spatiale en $O(1)$.

Exemple pas à pas pour x = 53 dans [9, 15, 27, 42, 53, 78] :

  • Itération 1 : debut = 1, fin = 6, milieu = 3 → T[3] = 27 < 53, donc debut = 4.
  • Itération 2 : debut = 4, fin = 6, milieu = 5 → T[5] = 53 = x, trouvé à l'indice 5 ! 
def recherche_dichotomique(T, x):
    debut, fin = 0, len(T) - 1
    while debut <= fin:
        milieu = (debut + fin) // 2
        if T[milieu] == x:
            return milieu
        elif T[milieu] < x:
            debut = milieu + 1
        else:
            fin = milieu - 1
    return -1

# Exemple d'exécution (indice 0-based : 4)
print("Indice :", recherche_dichotomique([9, 15, 27, 42, 53, 78], 53))
