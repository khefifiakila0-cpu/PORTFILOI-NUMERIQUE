Boucles & Conditions

🔢 Programme 1 : Somme et Moyenne avec Boucles

Objectif : Lire n notes réelles, calculer leur somme et afficher la moyenne avec vérification des cas invalides[cite: 10]. 

#include <stdio.h>

int main(void) {
    int n, i;
    float note, somme = 0.0f;

    printf("Nombre de notes : ");
    if (scanf("%d", &n) != 1 || n <= 0) {
        printf("Erreur : veuillez saisir un entier strictement positif.\n");
        return 1;
    }

    for (i = 1; i <= n; i++) {
        printf("Note %d : ", i);
        if (scanf("%f", &note) != 1) {
            printf("Erreur : saisie invalide.\n");
            return 1;
        }
        somme += note;
    }

    printf("Moyenne = %.2f\n", somme / n);
    return 0;
}

Exemple d'exécution dans le terminal :

Nombre de notes : 3 Note 1 : 13.5 Note 2 : 15 Note 3 : 16.5 Moyenne = 15.00

Points clés : L'initialisation somme = 0.0f évite les valeurs résiduelles en mémoire, et %.2f formate l'affichage à deux décimales[cite: 10].

Tableaux & Fonctions

📊 Programme 2 : Tableaux et Fonction de Recherche

Objectif : Parcourir un tableau d'entiers via une fonction dédiée pour extraire la valeur maximale[cite: 10]. 

#include <stdio.h>

int maximum(const int tab[], int taille) {
    int max = tab[0];
    for (int i = 1; i < taille; i++) {
        if (tab[i] > max) {
            max = tab[i];
        }
    }
    return max;
}

int main(void) {
    int valeurs[5] = {12, 45, 8, 67, 23};
    printf("Maximum du tableau : %d\n", maximum(valeurs, 5));
    return 0;
}

Exemple d'exécution dans le terminal :

Maximum du tableau : 67

Points clés : En C, un tableau passé à une fonction est transmis sous forme de pointeur vers son premier élément : il faut donc passer sa taille explicitement[cite: 10].

Pointeurs & Passage par Adresse

🧭 Programme 3 : Échange de Deux Valeurs par Pointeurs

Objectif : Modifier directement deux variables de main() depuis une fonction echanger() grâce à leurs adresses mémoire[cite: 10]. 

#include <stdio.h>

void echanger(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 10, y = 25;
    printf("Avant échange : x = %d, y = %d\n", x, y);
    echanger(&x, &y);
    printf("Après échange : x = %d, y = %d\n", x, y);
    return 0;
}

Exemple d'exécution dans le terminal :

Avant échange : x = 10, y = 25 Après échange : x = 25, y = 10

Points clés : Un passage par valeur classique ne modifierait que des copies locales ; l'opérateur d'adresse & et la déréférenciation * permettent d'agir sur les variables d'origine[cite: 10].

⚖️ Tableau Comparatif : Python vs Langage C

Critère Python Langage C
Syntaxe Très lisible, proche de l'anglais, blocs définis par l'indentation[cite: 10]. Plus stricte, utilisation d'accolades { } et de points-virgules ;[cite: 10].
Typage Dynamique (le type s'adapte automatiquement à la valeur)[cite: 10]. Statique (il faut déclarer explicitement int, float, char)[cite: 10].
Gestion mémoire Automatique grâce au ramasse-miettes (garbage collector)[cite: 10]. Manuelle via les pointeurs, malloc() et free()[cite: 10].
Rapidité Langage interprété, plus lent à l'exécution mais rapide à écrire[cite: 10]. Langage compilé (GCC) directement en code machine, très rapide[cite: 10].
