🧮 Mini-Projet 1 : Calculatrice Interactive

Description du problème : Réaliser un programme en console permettant d'effectuer les 4 opérations de base (+, -, *, /) avec gestion de la division par zéro et des erreurs de saisie. 

def calculatrice():
    try:
        a = float(input("Premier nombre : "))
        op = input("Opération (+, -, *, /) : ").strip()
        b = float(input("Deuxième nombre : "))
    except ValueError:
        print("Erreur : veuillez saisir des nombres valides.")
        return

    if op == "+":
        print("Résultat :", a + b)
    elif op == "-":
        print("Résultat :", a - b)
    elif op == "*":
        print("Résultat :", a * b)
    elif op == "/":
        if b == 0:
            print("Erreur : division par zéro impossible.")
        else:
            print("Résultat :", a / b)
    else:
        print("Opérateur invalide.")

calculatrice()

Exemple d'exécution :

Premier nombre : 12
Opération (+, -, *, /) : /
Deuxième nombre : 4
Résultat : 3.0

Explication : La fonction lit deux nombres flottants et teste l'opérateur avec if/elif/else. Le bloc try/except ValueError évite le plantage si l'utilisateur saisit du texte, et le test b == 0 protège la division.

Difficulté rencontrée & solution : input() renvoie une chaîne de caractères et peut provoquer une erreur de conversion ; résolu avec float(), .strip() et try/except.

🎲 Mini-Projet 2 : Jeu de Devinettes (Nombre Mystère)

Description du problème : L'ordinateur choisit un entier aléatoire entre 1 et 50 et guide l'utilisateur (« Trop petit » / « Trop grand ») jusqu'à la bonne réponse en comptant les essais. 

import random

secret = random.randint(1, 50)
essais = 0
trouve = False

while not trouve:
    try:
        proposition = int(input("Devine le nombre (1 à 50) : "))
    except ValueError:
        print("Veuillez entrer un entier valide.")
        continue

    essais += 1
    if proposition < secret:
        print("Trop petit !")
    elif proposition > secret:
        print("Trop grand !")
    else:
        print(f"Bravo ! Trouvé en {essais} essai(s).")
        trouve = True

Exemple d'exécution :

Devine le nombre (1 à 50) : 25
Trop grand !
Devine le nombre (1 à 50) : 14
Bravo ! Trouvé en 2 essai(s).

Explication : La boucle while répète la saisie tant que trouve est faux, incrémente essais à chaque tentative valide et compare avec le nombre secret.

Difficulté rencontrée & solution : Oublier d'incrémenter essais ou bloquer sur une saisie non entière ; corrigé avec essais += 1 après validation et try/except ValueError.

📒 Mini-Projet 3 : Gestionnaire de Notes Étudiant

Description du problème : Stocker les notes d'un étudiant dans une liste, calculer la moyenne, la note maximale/minimale et déterminer l'admission (moyenne ≥ 10). 

notes = []
try:
    n = int(input("Combien de matières ? "))
except ValueError:
    print("Erreur : veuillez entrer un entier.")
    n = 0

for i in range(n):
    while True:
        try:
            note = float(input(f"Note {i+1} (/20) : "))
            if 0 <= note <= 20:
                notes.append(note)
                break
            else:
                print("La note doit être comprise entre 0 et 20.")
        except ValueError:
            print("Veuillez saisir un nombre valide.")

if notes:
    moyenne = sum(notes) / len(notes)
    print("Notes :", notes)
    print(f"Moyenne : {moyenne:.2f} | Min : {min(notes)} | Max : {max(notes)}")
    print("Statut :", "Admis ✅" if moyenne >= 10 else "Ajourné ❌")
else:
    print("Aucune note enregistrée.")

Exemple d'exécution :

Combien de matières ? 3
Note 1 (/20) : 14
Note 2 (/20) : 11.5
Note 3 (/20) : 16.5
Notes : [14.0, 11.5, 16.5]
Moyenne : 14.00 | Min : 11.5 | Max : 16.5
Statut : Admis ✅

Explication : Les notes validées (entre 0 et 20) sont ajoutées dans la liste notes via append(), puis analysées avec sum(), len(), min() et max().

Difficulté rencontrée & solution : Formater la moyenne à 2 décimales et éviter la division par zéro si la liste est vide ; résolu avec {moyenne:.2f} et le test if notes:.
